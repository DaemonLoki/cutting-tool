# Only an aborted take is auto-dropped

A repeat is a retake only when the earlier attempt has no sentence end. That aborted span is dropped and the later take wins. A finished sentence that is said again stays in the rough cut with a CHECK marker, and the judge is not allowed to drop it. The judge may still drop an ambiguous aborted take, such as a long one or one whose retake seems to omit something. Any marker the judge leaves is resolved in Final Cut. The alternative was to drop every close repeat; that would cut deliberate restatements, which is the failure this tool is biased against.
