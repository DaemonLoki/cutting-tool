## Basics

### What is the topic?

**Top 3 skills to install for any frontend-related repo** - installing skills is super easy - you need node installed - and then use the `npx skills add <skills-url>` command - recommendation: `skills.sh` - Next.js projects - [Vercel React Best Practices](https://skills.sh/vercel-labs/agent-skills/vercel-react-best-practices) (for Vercel projects) - [Vercel composition patterns](npx skills add https://github.com/vercel-labs/agent-skills --skill vercel-composition-patterns) - [Next best practices](npx skills add https://github.com/vercel-labs/next-skills --skill next-best-practices) - [Web design guidelines](https://skills.sh/vercel-labs/agent-skills/web-design-guidelines) - [Frontend design ](https://skills.sh/anthropics/skills/frontend-design) - [Web Accessibility](https://skills.sh/supercent-io/skills-template/web-accessibility)

### What is the hook?

Show a basic design first and then transition it into an advanced one that looks fantastic

### What is the CTA?

Let me know if I missed an essential skill that leveled up YOUR designs
