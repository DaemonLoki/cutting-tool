## Agent skills

### Issue tracker

Issues and specs live as GitHub issues. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### User documentation

Keep `INSTRUCTIONS.md` synchronized with user-visible behavior. Any change to
the CLI, setup, prerequisites, artifacts, caching, exit codes, or implemented
feature status must update `INSTRUCTIONS.md` in the same change.
